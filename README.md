# 📊 Market Analysis Dashboard

## 📌 Project Overview
The Market Analysis Dashboard is an interactive Power BI project designed to analyze customer purchasing behavior, product performance, and overall sales trends. The dashboard provides valuable business insights through interactive visualizations and KPIs.

---

## 🎯 Objectives
- Analyze customer purchasing behavior.
- Identify top-performing products and categories.
- Monitor sales performance and revenue trends.
- Generate actionable business insights.

---

## 📈 Key Performance Indicators (KPIs)
- 👥 Total Customers
- 📦 Total Orders
- 💰 Total Revenue
- 💵 Average Order Value
- 🔁 Repeat Purchase Rate

---

## 🛠️ Tools & Technologies
- Power BI
- SQL
- Microsoft Excel
